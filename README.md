# viscenario.com

The Viscenario website: a static [Astro](https://astro.build) site on GitHub
Pages. It replaced the WordPress site in October 2026.

| Where | What |
| --- | --- |
| `site/src/content/` | Page text as Markdown: `products/`, `industries/`, `pages/`, one folder per language (`en/`, `nb/`). |
| `site/src/data/` | Shared details (`site.ts`: phone, email, offices, the contact-form key, menu words) and listings (`home.json`, `product-groups.json`, `customers.json`). |
| `site/src/assets/` | Logo and images, optimised to WebP at build time. |
| `site/public/` | Files served as they are: favicons, robots.txt, `CNAME`, the privacy PDF, and the redirect stubs. |
| `.github/workflows/deploy.yml` | Builds on every push to `main` and publishes `site/dist` — only the built site is ever served. |

## Working on it

```bash
npm --prefix site install
npm --prefix site run dev      # http://localhost:4322
npm --prefix site run build    # build and run every check, as the deploy does
```

Push to `main` and the workflow deploys it. If any check fails, nothing is deployed
and the run says why.

## What fails the build

- `scripts/check-pages.mjs`: a broken internal link or missing image; a page
  without a title, description or exactly one `<h1>`; an `<img>` without `alt`;
  a skipped heading level; a duplicate `id`.
- `scripts/check-old-urls.mjs`: every address the WordPress site answered
  (`scripts/old-urls.txt`, 169 of them) must still be a page or a redirect to one.

## Overflow sweep

`site/scripts/overflow-sweep.js` loads every page in the sitemap at 320, 390,
768, 1024, 1280 and 1440 pixels and reports any page wider than its viewport.
Serve `site/dist` (`python3 -m http.server 4400`), open
http://127.0.0.1:4400/404.html, and paste the script into the console.

## Redirects

English and Norwegian pages kept their WordPress addresses. German was not
carried over, the customer pages were all empty, and a few retired Dutch
addresses were still being forwarded; all of those are redirect stubs written into
`site/public/` by `scripts/make-redirects.mjs` (`npm run redirects`). Each is a
small page with a canonical link and a meta refresh, because GitHub Pages cannot
send a 301.

## Security

- Every page carries a Content-Security-Policy, generated by Astro with hashes
  for its own scripts and styles. The only outside origins allowed are the
  YouTube player (`youtube-nocookie.com`) and Web3Forms.
- There is no server, database or login to attack; the contact form posts
  straight to Web3Forms.
- `/favicon.ico` must exist; browsers ask for it whether or not a page declares
  it. `npm run favicons` regenerates the set from `src/assets/brand/mark.svg`.

## The contact form

It posts to [Web3Forms](https://web3forms.com). Set `web3formsKey` in
`site/src/data/site.ts`; while it is empty the form says so and offers the email
address instead of a button that would fail.
